# 知途 · 学生职业发展辅助决策平台

面向湖南交通工程学院学生的毕业设计原型 V0.3。Vue 3 + Vite + ECharts 前端，FastAPI + SQLAlchemy + Alembic 后端，**正式本地开发使用 MySQL 8.0 / 8.4**。不依赖云数据库、付费 API、学校 SSO 或 Docker；Docker 仅用于可选的开发验证。

**最新使用与验收见 [V0.3 功能审查及操作指南](docs/REVIEW_V3.md)**：新增13所高校与31专业资料、问卷CSV/XLSX导入向导、数据加工全景、实际DWS/ADS汇总与技能共现、五步业务路线和决策敏感性分析。SQLite/MySQL各101项后端测试与9项浏览器流程通过。正式技术路线见 [大数据技术实施方案](docs/FORMAL_PROJECT_PLAN.md)，此前功能见 [V0.2指南](docs/FEATURES_V2.md)。完整分布式仓库与 PySpark 实验仍为后续工作。

## 在你的 Windows 电脑运行

1. 安装 Python 3.12、Node.js 24 LTS（或 22.12+），启动已安装的 MySQL 服务。
2. 解压后进入实际项目目录，例如你当前的 `E:\my_master_DT_workpace\stan-main`。该目录下应直接存在 `backend`、`frontend`、`scripts`；更新源码时保留原有 `.env` 与数据库。
3. 在此目录打开 PowerShell，执行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\scripts\setup-local.ps1 -Demo
   powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1
   ```

安装脚本会询问本地 MySQL 主机、端口、用户名和密码，密码输入不回显。使用你自己的 MySQL 密码，不要改成下面的演示账户密码。默认创建独立数据库 `career_platform`；不删除已有数据库。已有 `backend/.env` 会保留。

启动脚本会打开本机浏览器；保持 PowerShell 窗口运行，按 Enter 停止本次启动的前后端。**这些步骤需要在你的电脑执行；当前云机器无法操作你的 E 盘。**

第一次安装或更新代码后运行一次 `setup-local.ps1`；以后的日常启动只需 `start-local.ps1`。升级到V0.3会自动迁移数据库、导入附件高校资料；保留原有 `.env` 与 MySQL 数据库。

详见 [Windows 操作与排错](docs/WINDOWS.md)，包含不用脚本的手工启动方法。

## 演示账户与验收流程

只在使用 `-Demo` / `--demo` 时创建下列公开演示账户。它们用于本机功能测试，不用于公网部署。

| 角色 | 用户名 | 演示密码 |
| --- | --- | --- |
| 学生 | `demo_student` | `DemoStudent123!` |
| 管理员 | `demo_admin` | `DemoAdmin123!` |

1. 打开右上角“演示数据”：查看 180 条**模拟**去向记录、35条模拟机会与独立的42条匿名模拟问卷；模拟问卷不会替登录用户伪造答案。
2. 学生登录 → 个人画像：填写 Python、SQL，城市长沙、衡阳，勾选多个意向，保存 V1。
3. 发展机会 → 生成我的推荐：查看按路径分组的技能匹配、差距和资格待核对提示。
4. 修改技能保存 V2，再生成推荐：画像时间线保留 V1，推荐历史保留当时的机会内容。
5. 管理员登录 → 数据工作台：使用 `data/demo-outcomes.csv` 导入模拟数据，查看接受、拒绝、重复率和完整率；重复导入不会新增事实记录。
6. 学生提交公开经验 → 管理员审核 → 公开可见 → 学生撤回后不再公开。
7. 职业探索 → 自愿填写30题 → 七角色解释与六维兴趣图 → 自主调整/隐藏；问卷星/腾讯导出可在管理员页面映射CSV列后接入。
8. 辅助决策 → 调整权重、比较最多6个机会 → 查看资格依据与技能差距 → 更新行动清单；数据洞察支持6种图表、表格和CSV导出。
9. 使用路线 → 查看五步流程与本人进度；学校概况 → 核对13所高校、31专业、人数差异与来源，筛选并对照高校。
10. 管理员 → 问卷导入：选择CSV/XLSX → 对应30题 → 预检 → 确认入库；数据加工全景 → 刷新仓库 → 查看ODS/DWD/DWS/ADS、技能规则与血缘。
11. 辅助决策 → 查看四组权重下的同路径名次变化 → 更新两周行动 → 第14天复盘并调整画像。

默认关闭演示模式。真实记录尚未导入时显示“暂无已核实数据”，不将模拟数字当学校就业率。

| 辅助决策 | 目标与准备检查、权重预设、最多6项比较、敏感性分析、行动复盘与历史快照 |

推荐分是参考排序分，不是就业/升学概率。复杂招考资格始终提示核对原文。报告汇总与逐人记录不可合并；不同逐人来源需分别选择。真实数据只允许导入获得授权且已匿名的记录。

这是可运行的增强原型。2026-10-14实际采集时衡阳栏目返回HTTP412，真实新增0条，任务保留受限原因；本地结果以运行报告为准。用户提供的高校数据已入库，来源待核验，不能当作官方就业率。当前仓库为MySQL关系型分层原型，学生洞察与决策仍读取机会事实，DWS/ADS在管理员页独立核对。**尚未实现或验证**：学校身份认证、官方报告指标核实、完整共享维表与分布式仓库、TF-IDF对照、PySpark性能实验、论坛评论/举报、整个账户删除流程和真实推荐效果实验。用户提供的方案保留在 [毕业设计原方案](docs/graduation-design-plan.md)，其中旧工程和测试结果不属于本工程。

## 手工开发与验证

后端工作目录是 `backend`，配置模板是 `.env.example`。使用 **Python 3.11–3.13，推荐 3.12**。前端工作目录是 `frontend`。

```powershell
# Windows / backend
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m alembic current
# 创建真实管理员，交互输入密码，不使用公开演示账户
.\.venv\Scripts\python.exe -m app.cli create-admin

# frontend
npm run build
```

默认测试使用独立 SQLite 测试库，覆盖业务行为。在一次性 MySQL 上执行同一套测试：

```powershell
# 仅对一次性开发 MySQL 使用；会反复重建 career_platform_tests 中的表。
# 如果这个数据库中已有你需要的数据，不要运行此命令。
$env:TEST_MYSQL = '1'
.\.venv\Scripts\python.exe -m pytest -q
Remove-Item Env:TEST_MYSQL
```

浏览器操作测试需要运行前后端，并准备演示数据。它会更新演示学生画像和测试来源，建议只针对独立验证数据库运行；重复运行会再增加两个画像版本，导入会跳过已有记录。

```powershell
# frontend：安装浏览器，再运行已有浏览器测试
npx playwright install chromium
npx playwright test
```

`.env`、数据库、日志、依赖目录和浏览器产物均被 Git 忽略。提交前使用 `git status --short` 检查，不要把个人 MySQL 密码、学生原始数据或 `.env` 上传。
