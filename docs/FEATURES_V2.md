## 1. 六项需求如何落地

| 用户需求 | 本次实现 | 入口 |
| --- | --- | --- |

| 衡阳公开网站采集与清洗 | 固定衡阳人社局栏目，robots→栏目→详情→清洗→原文/哈希→机会版本→运行报告 | 数据工作台→衡阳公告采集 |
| 接收调查问卷 | JSON/UTF-8 CSV 接口、问卷星/腾讯导出列映射、字段归一、缺失、质量报告与幂等导入 | 数据工作台→问卷接入 |
| 放大辅助决策 | 独立工作台，与数据洞察同级；权重调整、最多6机会比较、资格解释、技能差距、路径行动、历史快照 | 辅助决策 |

模拟问卷不替任何真实账户编造答案。学生必须自愿填写本人的问卷后才产生兴趣角色；专业、技能和考公意向不能自动替代兴趣测量。

## 2. 已有 Windows 工程如何升级

1. 停止先前启动的前后端。
2. 从 GitHub 下载新版项目 ZIP，将新版源码合并到当前工程。**保留你现有的 `backend\.env`、`backend\.venv` 和 MySQL 数据库**；这些本地文件不在 GitHub ZIP 中。
3. 在当前工程根目录执行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\scripts\setup-local.ps1 -Demo
   powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1
   ```

安装会执行新增迁移 `0003`，添加5张功能表，不清空原有业务记录；演示记录重复加载会跳过。数据库连接继续使用你的本地配置。现有问卷和角色属于自编探索工具，不能声称心理量表效度已得到验证。

## 3. 学生验收流程

1. 使用演示学生登录并开启“演示数据”。到个人画像填写 Python、SQL、MySQL，长沙/衡阳及多条发展意向，保存新版本；查看自报技能组合标签。
2. 进入职业探索，填写30道活动兴趣题并单独同意用途。每维至少4个有效回答、总计至少24题才自动给角色；“不了解”保持未知。
3. 观察六维兴趣图与七种动物拟人化伙伴，查看理由和体验建议。可调整展示角色或隐藏，原始兴趣分不被改写。
4. 进入辅助决策。调整技能/城市/专业权重，直接比较路径或选择最多6个具体机会。明确条件不符的自选机会会解释排除原因；未知条件提示核对原文。
5. 查看各路径的候选范围与差距，执行行动清单并更新“待开始/进行中/已完成”。分数只表示该路径内参考排序，不是成功率。
6. 更新画像再生成一份比较，历史记录仍引用旧画像和旧机会。撤回某份兴趣问卷时，会同时删除本人引用它的决策及行动进度，页面事先说明范围。

角色形象使用已有原创概念总图进行浏览器CSS展示裁切；七种形象已进入页面，但35张独立动作表情包尚未制作。

## 4. 问卷星与腾讯问卷的接入方式

### 4.1 导出及列映射

从平台导出问卷数据。如果得到 Excel 文件，先在本地另存为 **CSV UTF-8**。目前不直接读取 `.xlsx`，也不连接问卷平台的私有API。

在数据工作台→问卷接入选择文件或粘贴CSV，选择模拟/真实授权类型，并填写来源名称。真实记录同时需要管理员确认数据授权，以及每份答卷明确的本人同意字段。

标准模板：`data/survey-template.csv`。JSON示例：`data/survey-example.json`。原始题目编号为 `R1…R5、I1…I5、A1…A5、S1…S5、E1…E5、C1…C5`，计分范围1—5。导出选项应设置数字编码；未知留空，不填0。

中文导出可通过“标准字段→导出列名”映射，例如：

```json
{
  "response_id": "答卷编号",
  "consent": "同意授权",
  "major": "专业",
  "graduation_year": "毕业届次",
  "R1": "第1题",
  "R2": "第2题",
  "I1": "第6题"
}
```

按你问卷的实际列名逐字对应其余题目。未映射题目保持未知；没有至少一道对应题目会拒绝导入。对于“提交时间、用时”等无关元数据，填写忽略列。姓名、电话、邮箱、学号、IP等列自动排除，也不能映射成匿名身份字段。没有独立匿名学生键的导出，在答卷编号与来源范围内生成去标识键；它只能识别答卷，不能据此关联真实账户或跨问卷同一人。

### 4.2 接口契约

| 接口 | 请求 | 权限 |
| --- | --- | --- |
| `GET /api/interests/instrument` | 获取30题、稳定编号、版本和角色定义 | 可读取工具说明 |
| `POST /api/interests/responses` | 本人 `instrument_version,profile_version,answers,consent,submission_id` | 学生登录；当前画像版本 |
| `GET /api/profile/roles` | 本人当前兴趣解释与显示偏好 | 本人 |
| `PATCH /api/profile/roles/display` | `display_role,hidden` | 本人；只改展示 |
| `DELETE /api/interests/responses/{id}` | 撤回本人测量及其关联决策 | 本人 |
| `POST /api/admin/import/surveys` | `{source_name,data_kind,authorized_consent,records}` | 管理员登录 |
| `POST /api/admin/import/surveys/csv` | `{source_name,data_kind,authorized_consent,csv_content,field_mapping,ignore_columns}` | 管理员登录 |

外部接收接口使用本项目管理员会话 `Authorization: Bearer …`，不提供无认证公开写入。问卷平台导出或获准的对接程序可调用这些接口；平台原始账号/密码不交给本项目。

JSON的一条标准记录：

```json
{
  "response_id": "survey-0001",
  "student_key": "anonymous_000001",
  "major": "数据科学与大数据技术",
  "graduation_year": 2027,
  "skills": ["python", "SQL"],
  "cities": ["衡阳市"],
  "intents": ["employment", "postgraduate"],
  "answers": {"R1": 4, "I1": 5, "C1": null},
  "consent": true
}
```

该例缺失多数题目，接收后会标记信息不足，不自动生成心理标签。记录`source_name+data_kind+response_id`唯一；一致重复跳过，冲突拒绝。质量报告给出接受/拒绝/重复、完整率、规则与源文件哈希。只留存通过授权与字段验证的白名单原始记录；拒绝行仅保留行号和错误码，不保存未授权或非法答案值。

外部匿名问卷与账户绑定的本人问卷分开，不擅自将外部学生键与本地登录账户连接。问卷样本也不会直接计入实际毕业去向。

## 5. 衡阳公告采集的真实边界

目前登记的来源是：`https://www.hengyang.gov.cn/hysrsj/ywgz/sydwgkzp/index.html`，来源编号 `hengyang_hr_public`。完整流程实现了该来源的栏目与详情解析、公开规则检查、网络限制记录、原始HTML留存、哈希、去重与版本、清洗结果、管理员审计和模拟回退。HTML解析用例是手工构造的测试样例，不是真实采集成果。

本次云环境实际请求 `robots.txt` 被出站代理以HTTP403拒绝，**真实公告新增0条**。没有关闭TLS、绕过限制或把模拟记录显示成真实成功。学生本地可以在管理员页面发起同一流程；本机网络、robots规则或网站模板仍可能影响结果，请以运行报告为准。栏目读取验证通过不等于招聘附件或每个岗位资格已经解析。

当前只读取HTML公告；PDF/Excel职位附件需人工核对。公告按条目存储，不声称一条公告等于一个岗位或招聘人数。发布日期、截止、技能和专业条件缺失时保持未知。展示正文最多10,000字符，完整原文存入MySQL LONGTEXT；截断后的正文变化仍按完整文本哈希判断版本。

可调用：

```text
GET  /api/admin/crawler/sources
POST /api/admin/crawler/run
GET  /api/admin/crawler/runs

POST 请求：
{"source_id":"hengyang_hr_public","limit":5,"allow_demo_fallback":true}
```

`allow_demo_fallback` 默认关闭；勾选后，受限时插入/跳过已有模拟样本，真实失败保留在报告`errors`。一轮最多10个内容页（栏目页计1），间隔至少1秒；不接受任意URL。更慢的robots策略会中止交互采集并报告。

## 6. 辅助决策及可视化

辅助决策将可观察技能、城市、专业与资格核对分开。仅用已知项归一，用户可调权重；未知项不是0。兴趣角色用于探索行动，不做岗位硬过滤。历史保存画像版本、机会版本、规则、权重和结果，行动进度独立于原始比较证据。详情见 [决策说明](DECISION.md)。

数据洞察按公开/模拟数据、专业、城市、路径、发布日期筛选，取每个来源记录的最新机会版本。六种图表可切为原始汇总表，并导出CSV；明示来源、发布日期未知、已过期及截断的图表维度范围。城市×技能中同一条公告同一技能只计一次，多项技能总数不等于公告总数。

实际毕业去向仍在发展总览独立统计，保留来源选择、观察日、届次和小样本保护；机会统计不能冒充学校就业率。界面不填造工资、学校办学规模或个人成功率。
