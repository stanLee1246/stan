# 数据字典与统计口径（第一版）

V0.3新增高校资料、关系型DWS/ADS、技能共现分母与导出文件契约见 [审查指南](REVIEW_V3.md)。学校在读人数与原文就业率不同口径；就业率原值仅复核，不能与逐人毕业去向混合统计。

V0.2 新增问卷、角色、决策与采集数据契约见 [功能指南](FEATURES_V2.md)。新增原文表使用 LONGTEXT；问卷仅保留授权且有效的记录，拒绝行只留错误码。

## 分类轴

`stage` 表示当前阶段，不是实际去向；`intents` 是多选发展意向；`organization_type` 是单位性质，不与升学/公务员混排。`path` 在机会与去向中按不同枚举校验：

| 标识 | 含义 | 可作为机会/意向 | 可作为实际去向 |
| --- | --- | --- | --- |
| employment | 企业就业 | 是 | 是 |
| postgraduate | 升学/研究生项目 | 是 | 是 |
| civil_service | 公务员 | 是 | 是 |
| public_institution | 事业单位 | 是 | 是 |
| internship | 实习 | 是 | 否 |
| unresolved | 待落实 | 否 | 是 |
| other | 其他 | 否 | 是 |

## 去向 CSV

使用 `data/outcome-template.csv`，UTF-8 编码，表头必须完全一致（列顺序可变），每批最多 2000 行，输入最多 500000 个字符。**不得包含姓名、电话、学号或其他额外列**。示例数据是模拟记录，不代表真实校友。

| 字段 | 约束 |
| --- | --- |
| student_key | 6–64 位随机匿名标识，仅 ASCII 字母、数字、`_`、`-`；由授权方生成，不能使用真实学号或简单可逆编码 |
| major | 精确专业名称，2–100 字符；不将“护理”和“护理学”等自动合并 |
| graduation_year | 2000 至当前年；实际去向不能为未来届次 |
| path | 上述实际去向枚举 |
| city | 可空，空表示未知；仅按显式别名字典归一，如“长沙市”→“长沙” |
| observed_on | ISO 日期，不能早于毕业届次或晚于今天 |
| confirmation_status | `simulated`、`self_report`、`school_confirmed`；真实/模拟不能混用；真实确认状态由数据授权方负责，本系统没有学校核验接口 |
| source_record_id | 1–80 字符，原始来源中的记录编号 |
| source_url | 无凭据的 HTTP/HTTPS 来源 URL，最长255字符；不能包含密码或身份参数 |

去重键为 `(source_name, student_key, observed_on)`。完全相同记录跳过；同键不同内容拒绝，不覆盖。重复导入仍保留新批次审计，但不会重复计入事实记录。更新实际去向应新增观察日快照。多个来源可能含同一学生，因此统计接口要求选择一个来源。

公开报告百分比不得伪造为逐人记录。该版本还没有报告汇总指标导入模块。

## 原始批次与质量

每批存原始 CSV、SHA-256、清洗版本 `outcome-v1`、来源、操作者和时间。质量结果保存：总数、接受数、拒绝数、重复跳过数、字段完整率、校验通过率、重复率和前50条错误行号。

校验通过率 `(接受+一致重复)/总数`；重复率 `一致重复/总数`；完整率 `非空字段数/(总行数×模板字段数)`。可空城市也纳入完整率。解析准确率留空，必须人工抽样核对后另做实验，不把格式校验率称为解析准确率。

## 画像与推荐

画像主键 `profile.id` 是代理键；`user_id + version` 唯一，`valid_from/valid_to/recorded_at` 记录历史。保存时原子检查 `expected_version`，成功创建新版本，并结束旧版本。技能、城市、意向存桥接表；技能证据当前为 `self_report`。

推荐固定权重 `技能0.50、城市0.30、专业0.20`，只对可观测项归一化。空技能或城市代表未知；至少有两个可观测项才输出分数。公开招考中的年龄、政治面貌、应届要求、专业目录等没有被完整建模，始终提示人工核对。当前学历表示在读/自报层次，不意味着已经取得要求的证书。

推荐记录保存画像版本、模型版本、生成时间、机会版本和完整展示快照；后续机会修改不改变历史结果。

## 图表与隐私

图表统计同一来源下每名匿名毕业生在截止观察日的最新记录。分组字段：专业、届次、实际去向、目的城市。它描述授权样本，不能直接称为学校就业率。

真实样本不足5人时隐藏总数及所有分布；任一类别不足5人时隐藏对应整项分布，以降低利用总数相减推断的风险。**这只是第一版阈值保护，不是差分隐私或完整匿名证明**；公开部署前需补充跨查询推断防护、数据授权管理、撤回与删除流程。
