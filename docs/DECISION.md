# 职业发展辅助决策模块

V0.3规则为`observed-decision-v2`：新增准备检查、可选问卷提示、三组权重预设与第14天复盘；响应中的`decision_context`保存生成时目标和缺失信息，`sensitivity`保存固定本次清单的四组路径内名次。并列同名次、未知与排除项不强行排序，少于两个可评分对象不判断稳定性。两者与原始证据一起留在历史，更新行动不会重算。当前操作见 [V0.3指南](REVIEW_V3.md)。

本模块将辅助决策与数据可视化并列展示。学生保存个人画像后，可以选择就业、实习、升学、公务员或事业单位中的多条路径，分别查看机会线索、条件证据、技能差距与两周行动计划。系统不将不同人生路径汇总成一个分数，也不替学生决定发展方向。

## 决策流程

1. 保存专业、学历、自报技能、城市偏好和发展意向。
2. 选择公开机会或明确标注的模拟机会。最多手动比较六条；未手动选择时，系统从至多一百条最新机会中按意向路径轮流选取至多六条。
3. 分别查看结构化硬条件、技能覆盖、城市偏好及专业条件的证据；不符合明确硬条件的手动选择项仍显示排除原因，但不给匹配分。
4. 调整技能、城市、专业的权重，重新生成方案；权重不会改变学历、专业、报名截止日期等硬条件校验。
5. 将原文核验、技能练习和路径探索转化为两周任务，记录待办、进行中或完成状态。
6. 在历史方案中回看当时的画像版本、机会版本、权重和证据。

## 匹配与未知信息

默认权重为技能 `0.5`、城市 `0.3`、专业 `0.2`。对于有观测依据且权重大于零的维度，匹配分为：

```text
100 × Σ(有效维度权重 × 维度值) / Σ有效维度权重
```

技能值为已自报技能覆盖机会技能的比例；城市值为机会城市是否在城市偏好内；专业值为结构化专业名称是否匹配。至少有两个有效观测维度才能显示匹配分。未填技能不是不会技能，未知城市不是城市不匹配，来源未列专业要求也不等于专业不符合；未知项保持空值，不按零分处理。比较时必须同时查看有效维度及 `observed_weight`，信息缺失较多的高分不能视为已经完整匹配。

这是一套可解释的规则排序方法，不是心理测量分数，也不是录用、录取或上岸概率。自报技能没有经过能力验证；专业目录、年龄、应届身份、政治条件、户籍、证书等复杂资格必须阅读官方原文。考试类路径及结构化条件缺失的机会始终提示人工核对。角色及兴趣问卷只用于附加探索建议，不改变资格、评分或硬筛选。

## 接口

所有接口均要求登录，且只能读取、修改本人的决策方案。

| 方法与路径 | 功能 |
|---|---|
| `POST /api/decisions/compare?data_kind=public` | 创建、保存并返回方案；`data_kind` 可为 `public` 或 `demo` |
| `GET /api/decisions/history` | 返回本人最近三十条方案及行动状态 |
| `GET /api/decisions/{id}` | 返回本人指定历史方案 |
| `PATCH /api/decisions/{id}/actions/{action_id}` | 设置行动状态，返回更新后的方案 |

创建请求示例：

```json
{
  "opportunity_ids": [1, 2],
  "weights": {"skills": 0.5, "city": 0.3, "major": 0.2}
}
```

`opportunity_ids` 可省略，由系统生成跨意向路径的候选展示。手动选择仅接受一到六个不重复正整数；不存在、模拟/公开类型不一致或已被更新版本替代的编号返回 `422`，前端应刷新机会列表。权重为非负有限数，总和必须大于零，无需固定为一。

返回方案包含 `profile_version`、`model_version`、`generated_at`、`data_kind`、`weights`、`paths`、`comparisons`、`action_plan` 与 `notice`。其中 `paths` 覆盖学生所有已选意向，并按路径列出候选数、待核对数、已知截止时间数和技能差距频次；数量仅代表本次受限机会池，不是所有招聘机会的总量。`comparisons` 的每个机会保留来源、机会版本、分项权重与证据、排除原因、资格状态及截止日距今天数。

更新任务请求：

```json
{"status": "doing"}
```

支持 `todo`、`doing`、`done`，允许学生根据实际进展调整。行动编号由路径和任务语义稳定生成。

## 历史记录与数据边界

`fact_decision_run` 保存原始画像外键和版本、完整机会快照、模型版本、准确请求配置以及不可修改的 JSON 证据。行动进度单独保存在 `action_states`，读取时与原始方案合并。更新画像、发布机会新版本或调整行动状态，都不会重算旧记录的比较结果。

公开机会与模拟机会分别生成决策方案。模拟数据用于演示和测试，不能用于实际报名。即使暂时没有候选机会，方案仍提供原文搜集、画像证据补充和各路径的两周探索任务，帮助学生继续准备。
