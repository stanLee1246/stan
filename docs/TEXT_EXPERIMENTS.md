# 推荐方法对照：结构化规则与 TF-IDF 词面基线

本功能位于“推荐方法对照”页面。它为数据科学毕设提供一个可以运行、复核和解释的算法对照，而不是宣称某种算法已取得更高推荐准确率。登录学生保存画像后，可以在同一路径、同一候选集上对照两种方法，并下载 Markdown 报告或完整 JSON。

## 业务流程

1. 保存画像：选择发展意向，填写技能、项目经历、城市、专业和学历。
2. 选择公开来源或模拟演示。两类数据完全隔离。
3. 从同一来源 URL、来源编号的最高版本快照中，按最新记录 ID 筛选候选；明确过期、专业不符、学历不足、意向之外的记录共同排除。未知条件保留“资格待核对”。
4. 最多取 100 条符合已知条件的候选，分别按发展路径拟合词表和 IDF。达到上限时明确提示范围，排除统计仅表示实际检查过的快照。
5. 同一机会显示两种方法的分数、路径内名次、缺失维度、共同词片段与贡献。并列分数同名次，无正文本相似度时不排名。
6. 核对原文，返回辅助决策制定行动。实验不写入数据库，也不自动覆盖决策或画像。

## 方法 A：结构化规则

复用辅助决策的 `compare_opportunity` 实现，避免两个页面存在不同资格定义。权重固定为技能 0.5、城市 0.3、专业 0.2。

- 技能：自报技能与机会明确技能要求的覆盖率；自报技能为空表示未知。
- 城市：机会城市是否在显式偏好中；缺少城市或偏好表示未知。
- 专业：结构化专业名匹配。专业不符先作为资格排除。
- 至少两个有观测依据的维度才生成 0–100 路径内关联分；仅对有观测的维度重新归一化。

## 方法 B：TF-IDF 与余弦

只把本人自报技能和项目经历作为查询文本。专业、学历、意向作为资格过滤依据；城市属于显式偏好，不加入文本；兴趣角色与心理特征不参与计算。仅填写专业时不生成“文本偏好”。

机会文档由标题、标准化技能及描述前 4,000 字组成。说明是否截断，完整原文入口保留。文字执行 NFKC 和英文小写归一化，删除 HTML 标记；英文保留常见技术标识如 `python`、`sql`、`c++`、`c#`，中文取不跨标点的相邻双字片段并去除固定停用片段。中文双字片段是可复现的简化实现，不等于语言学分词，也不能理解同义词。

设同一路径冻结候选语料包含 N 条文档，df(t) 是含 t 的文档数：

```text
idf(t) = log((1 + N) / (1 + df(t))) + 1
TF(t,d) = 1 + log(count(t,d))，count > 0
w(t,d) = TF(t,d) * idf(t)
v(d) = w(d) / ||w(d)||₂
cosine(q,d) = Σ v(q,t) * v(d,t)
```

查询使用候选语料的冻结 IDF，未出现在词表中的查询片段不加入向量。查询没有语料内片段、或文档无有效片段时，相似度为 `null`，表示没有可用向量；有效查询与某文档无共同片段时为 0。0 分不排名。非负权重使余弦位于 0–1。

每条机会最多展示八个贡献最高的共同片段，并提供原始词频、IDF、片段贡献、全部贡献和未展示尾部贡献。片段贡献为两个 L2 归一化向量对应分量的乘积，所有片段贡献相加可复算余弦。

## 可复核性与接口

```http
POST /api/experiments/recommendations?data_kind=demo
Authorization: Bearer <本人会话>
```

无请求体要求。未登录返回 401；未保存画像返回 422。接口只读取本人画像与公开机会，不读取其他用户画像、问卷答卷或心理特征，也不保存文本实验记录。

返回内容包括：

- `model_version`、`profile_version`、数据类型、生成时间和查询指纹。
- 全范围最新快照数、实际检查数、共同候选数、100 条上限和是否触顶；明确标注排除原因统计是否完整。
- 各路径冻结语料指纹：按机会 ID、版本和实际使用文本 SHA-256 生成。
- 相同候选的结构化分数与余弦、各自路径内名次、缺失维度、词片段解释。
- TF、IDF、归一化、文本字段、描述上限、词法规则及单次计算耗时。

JSON 导出保留可复核字段，Markdown 报告便于论文和答辩记录。报告包含本人的技能和项目描述，分享时应自行选择范围。实验输出没有持久化历史；需要复现时应保留报告及对应机会版本。

## 指标与边界

规则 0–100 和余弦 0–1 是不同量纲，不混合相加；不跨路径比较，也不表示录用、录取、上岸或成功概率。样本文本写法、语料规模和快照变化都会影响 TF-IDF。模拟数据只能验证流程、数值公式及信息隔离，不能证明真实推荐有效。

当前没有经过授权并人工标注的“学生—机会相关性”真值。准确率字段为 `null`，不生成虚假的 Precision、Recall、NDCG 或显著性结果。后续取得标注时，应预先定义相关等级、按学生隔离训练与测试、冻结评估候选集，并报告样本数量和划分，才能评价两种方法的真实效果。

单次服务器耗时包含数据库读取，受负载和缓存影响，属于本次运行信息；没有重复测量或实验控制，不据此宣称模型速度优劣。
